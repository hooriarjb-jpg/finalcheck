# FinalCheck — Deploy-ready MVP

FinalCheck compares an approved source with a final draft and flags facts that may have disappeared or changed before publication.

## V1 checks
- Dates
- Times
- Prices
- URLs
- Emails
- Numbers
- Likely proper-name phrases
- Required wording

## Start here
Open `DEPLOY.md` for the exact online deployment steps.

## Product status
This build is intentionally a small validation MVP. It does not yet include:
- user accounts
- billing
- saved projects
- private organization workspaces
- semantic AI comparison
- production-grade security/privacy controls
